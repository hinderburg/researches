# TOADBREW — Alchemical Arena
## Game Design Document — концепт

> **Рабочее название:** TOADBREW  
> **Жанр:** mobile tactical PvP / physics battler  
> **Формат:** 1v1, по 2 механические жабы на игрока  
> **Камера:** вид сверху под небольшим углом  
> **Управление:** оттяжка → прогноз параболы → отпускание → прыжок → impact  
> **Сессия:** ориентир 3–5 минут  
> **Главная идея:** один и тот же простой физический toy создаёт позиционирование, урон, разрушение арены и алхимические комбинации.

---

# 1. High Concept

Два алхимика выставляют на арену по две механические жабы — латунно-железных боевых автоматонов в средневековом стиле. На спине каждой жабы закреплены **три стеклянные колбы**, заполненные выбранными игроком алхимическими жидкостями.

Во время боя игрок не выбирает атаки из панели способностей. Основное действие всегда одно:

**оттянуть жабу → выбрать силу и направление → отпустить → жаба летит по параболической траектории → приземление создаёт эффект.**

Каждый завершённый прыжок переключает активную колбу на следующую. Поэтому игрок заранее собирает не только пару жаб, но и **последовательность трёх реагентов на спине каждой из них**.

Главная глубина появляется из комбинаций:

- активная жидкость + поверхность на арене;
- активная жидкость + активная жидкость союзной жабы;
- уникальная механика самой жабы + результат реакции;
- физическое столкновение + позиция + разрушаемое окружение.

Игрок должен понимать базовый эффект каждой жидкости с первого взгляда, а усиленные реакции строятся из простых пар цветов.

# 2. Дизайн-пиллары

## 2.1. Toy прежде правил

Само действие должно приносить удовольствие независимо от меты:

`Pull → Aim → Release → Arc → Impact → Reaction`

Игрок должен получать удовольствие от:

- натяжения механической жабы назад;
- сжатия её пружин и лап;
- визуального прогноза дуги;
- полёта тяжёлого механизма;
- удара о землю или другую жабу;
- разлета камней, искр, жидкости и деталей арены;
- физического knockback;
- изменения поля после приземления.

## 2.2. Одно действие — много последствий

Отдельных кнопок `Move`, `Attack`, `Skill 1`, `Skill 2` нет.

Прыжок одновременно может:

1. переместить жабу;
2. ударить противника;
3. вытолкнуть его;
4. разбить объект или участок арены;
5. создать алхимическую зону;
6. вызвать реакцию с уже существующей зоной;
7. связаться со второй своей жабой и подготовить усиленный следующий прыжок.

## 2.3. Две жабы важнее одной

Команда состоит только из **двух персонажей**, поэтому комбинация пары должна ощущаться сильнее, чем подбор множества маленьких пассивных бонусов.

Хорошая пара отвечает на вопрос:

> «Что эти две жабы могут сделать вместе такого, чего каждая из них не может сделать отдельно?»

## 2.4. Арена запоминает действия игроков

Как в системных RPG, результат предыдущего действия остаётся на поле:

- яд;
- огонь;
- лёд;
- трещины;
- разрушенные объекты;
- ослабленные участки пола.

Следующий прыжок может использовать последствия предыдущего.

## 2.5. Комбинации должны читаться без таблицы в голове

Игрок не обязан запоминать реакции.

При наведении траектории игра заранее показывает:

- иконку активной колбы;
- цвет зоны приземления;
- название возможной реакции;
- прогноз урона / knockback / разрушения.

Например:

**RED + GREEN → BLAST**

И рядом три простые пиктограммы:

`damage ↑  |  knockback ↑  |  terrain crack`

# 3. Что адаптируется из Divinity: Original Sin 2 PvP

В качестве референса используются не конкретные способности DOS2, а несколько правил системного боя:

- небольшие арены, построенные для тактического PvP;
- уникальные персонажи с собственными наборами сильных сторон;
- Deathmatch как простое основное условие победы;
- поле боя как часть боевой системы;
- поверхности и элементы, которые можно наслаивать и комбинировать;
- поздняя эскалация матча, не позволяющая бесконечно избегать боя.

В оригинальном Arena Mode DOS2 есть Deathmatch и Kill the King, отдельные PvP-арены, уникальные персонажи, сундуки и Mutators. В TOADBREW это **сильно упрощается**: один основной режим — командный Deathmatch 2v2, без лута и без набора заклинаний.

Главный перенесённый принцип:

> **первое действие меняет арену, второе использует созданное состояние.**

# 4. Сеттинг

## 4.1. Мир

Алхимические гильдии средневекового мира больше не выясняют отношения войнами. Вместо этого они строят боевых механических жаб и выставляют их на официальные арены.

Каждая жаба собрана из:

- бронзы;
- железа;
- дерева;
- кожаных ремней;
- пружин;
- цепей;
- клапанов;
- стеклянных колб;
- алхимического реактора.

Жабы нарочито механические, но сохраняют узнаваемую анатомию реальных жаб и лягушек.

## 4.2. Внешний вид жаб

Общий визуальный язык:

- тяжёлые шарнирные лапы;
- большая голова и читаемый силуэт;
- механический язык у соответствующего типа;
- пружины вместо части сухожилий;
- три хорошо видимые колбы на спине;
- цвет активной колбы подсвечивает трубки и руны на корпусе.

У каждой жабы должно быть **2–4 ярких отличительных признака**, читаемых даже с игровой камеры.

---

# 5. Арена

Арена больше не является прудом.

Визуально это смесь:

- средневекового турнирного двора;
- алхимической лаборатории;
- гладиаторской арены;
- тактических арен в духе Battlerite / Divinity.

## 5.1. Базовая арена

Компактная симметричная площадка:

- каменный пол;
- центральная открытая зона;
- несколько колонн;
- низкие стены;
- алхимические резервуары;
- декоративные каналы;
- 4–8 разрушаемых объектов;
- несколько заранее повреждённых участков пола.

Арена не строится из клеток визуально, но логика столкновений и зон может использовать скрытую сетку.

## 5.2. Разрушение

У объектов есть максимально простые состояния:

`INTACT → CRACKED → DESTROYED`

Разрушаются:

- колонны;
- бочки;
- алхимические резервуары;
- статуи;
- хрупкие плиты пола.

Некоторые отмеченные плиты могут провалиться.

Обычный прыжок редко разрушает прочный объект за один удар. Для быстрого разрушения нужны:

- тяжёлая жаба;
- высокая скорость;
- Force-колба;
- комбинированная реакция;
- повторный удар по уже треснувшему объекту.

## 5.3. Провалившийся пол

Провал не является мгновенной смертью.

Если жаба падает в разрушенный участок:

- получает фиксированный environmental damage;
- оказывается в нижнем углублении;
- на следующей активации может выпрыгнуть обратно.

Так разрушение важно тактически, но одна ошибка не заканчивает матч.

# 6. Структура матча

## 6.1. Команды

Игрок A:
- Frog A1
- Frog A2

Игрок B:
- Frog B1
- Frog B2

## 6.2. Раунд

Каждая жаба может активироваться **один раз за раунд**.

Пример порядка:

1. A активирует одну из своих жаб.
2. B активирует одну из своих жаб.
3. A активирует оставшуюся.
4. B активирует оставшуюся.

В следующем раунде первым начинает другой игрок.

Это:
- заставляет использовать обеих жаб;
- снижает возможность спама одной сильной комбинацией;
- делает подготовку связки из двух персонажей читаемой.

## 6.3. Активация

В свою активацию игрок:

1. выбирает доступную жабу;
2. зажимает её;
3. тянет назад;
4. видит прогноз;
5. отпускает;
6. прыжок полностью разрешается;
7. применяется impact;
8. применяется колба;
9. разрешается реакция;
10. активная колба переключается на следующую.

Отдельного подтверждения после отпускания нет.

---

# 7. Основной toy: прыжок

## 7.1. Оттяжка

Положение пальца относительно жабы задаёт:

- направление;
- силу;
- высоту / дальность параболы.

До отпускания видны:

- дуга;
- landing circle;
- объект первого столкновения;
- потенциальная реакция.

## 7.2. Полёт

Во время полёта игрок больше не управляет жабой.

Жаба может:

- пролететь над низкими объектами;
- столкнуться с высокой колонной;
- попасть в другую жабу;
- упасть на поверхность;
- задеть разрушаемый объект.

## 7.3. Прямое попадание во врага

Если жаба попадает непосредственно в противника:

1. наносится **Impact Damage**;
2. цель получает knockback;
3. эффект активной колбы создаётся вокруг точки столкновения;
4. если там уже есть другая алхимическая поверхность — срабатывает реакция.

Прямое попадание — один из наиболее сильных исходов прыжка, но не единственный полезный.

---

# 8. Базовые характеристики жаб

Каждая жаба имеет четыре читаемых параметра.

## HP
Сколько урона может получить.

## Impact
Урон прямого физического столкновения.

## Mass
Влияет на:
- knockback, который получает жаба;
- knockback, который она наносит;
- разрушение окружения.

## Jump
Максимальная дальность базового прыжка.

В бою игроку постоянно показываются только HP и активная колба. Остальные значения представлены в карточке персонажа и через прогноз.

# 9. Колбы

## 9.1. Три слота

У каждой жабы на спине находится:

`[ I ] [ II ] [ III ]`

Перед матчем игрок заправляет каждый слот.

Например:

`EMBER → FORCE → VENOM`

Порядок важен.

## 9.2. Переключение

В начале матча активна колба I.

После каждого **завершённого собственного прыжка**:

`I → II → III → I`

Не переключают колбы:

- knockback;
- притягивание языком;
- падение из-за разрушения;
- перемещение чужой способностью.

Таким образом игрок всегда может заранее знать следующую жидкость.

## 9.3. Правила заправки

Для MVP доступны четыре базовые жидкости.

Игрок выбирает для каждой жабы любые **3 разных** жидкости из четырёх и задаёт их порядок.

Дубликаты внутри одной жабы в MVP запрещены, чтобы:

- каждый цикл имел вариативность;
- последовательность имела значение;
- игроку было проще читать вражеский билд.

Позже отдельные архетипы могут разрешать дубликаты как специальное правило.

## 9.4. Открытая информация

Три колбы хорошо видны на модели.

Противник видит:

- их цвета;
- порядок;
- текущую активную колбу.

Активная колба:
- светится;
- подсвечивает трубки на корпусе;
- имеет увеличенную UI-иконку рядом с HP.

Никаких скрытых реакций.

# 10. Четыре базовые жидкости

## 10.1. Ember — красная

**Базовый эффект:**
- небольшой дополнительный landing damage;
- создаёт маленькую горящую зону на 2 активации.

**Простая идея:** damage.

## 10.2. Venom — зелёная

**Базовый эффект:**
- накладывает Poison;
- создаёт ядовитую зону.

Poison наносит небольшой урон после следующей активации заражённой жабы.

**Простая идея:** damage over time.

## 10.3. Frost — синяя

**Базовый эффект:**
- накладывает Chill;
- создаёт холодную зону.

Chill уменьшает максимальную дальность **следующего** прыжка, затем снимается.

**Простая идея:** меньше mobility.

## 10.4. Force — жёлтая

**Базовый эффект:**
- повышенный knockback;
- +1 уровень damage разрушаемому окружению в точке impact.

Долгой поверхности не оставляет; вместо неё на короткое время остаётся жёлтый знак Resonance, который может участвовать в реакции.

**Простая идея:** push + destruction.

# 11. Реакции жидкостей

Комбинации используются только парами.

Третьего слоя элементов нет.

## 11.1. Два одинаковых эффекта

Если совпали одинаковые жидкости:

### OVERCHARGE

Просто увеличивается базовый эффект.

Пример:
- Ember + Ember = больше damage / больше fire area;
- Force + Force = сильнее knockback и разрушение.

Игроку не нужно учить отдельную механику.

## 11.2. Разные жидкости

| Комбинация | Реакция | Результат |
|---|---|---|
| Ember + Venom | **Blast** | взрыв: высокий AoE damage + трещина на окружении |
| Ember + Frost | **Steam Burst** | поверхности исчезают, все рядом получают сильный knockback |
| Ember + Force | **Meteor** | усиленный impact + большой урон объектам/полу |
| Venom + Frost | **Noxious Ice** | увеличенная зона, одновременно Poison + Chill |
| Venom + Force | **Corrosive Burst** | небольшой AoE damage + цель становится Corroded: следующий физический impact по ней сильнее |
| Frost + Force | **Shatter** | мгновенный burst по цели + высокий damage уже треснувшему окружению |

Главное правило:

> **реакция всегда сильнее двух отдельных базовых эффектов, но требует подготовки.**

# 12. Как получить комбинацию

Есть два основных способа.

## 12.1. Surface Reaction

Жаба с активной колбой приземляется в зону другого типа.

Например:

1. первая жаба оставила Venom;
2. противник или союзник находится рядом;
3. вторая жаба с Ember приземляется в зелёную область;
4. происходит **BLAST**.

Это основной принцип, адаптированный из системных elemental surfaces.

## 12.2. Ally Link

Игрок может использовать вторую жабу как живой алхимический усилитель.

### Создание Link

Если своя жаба приземляется непосредственно на союзника:

- союзнику не наносится урон;
- прыгнувшая жаба мягко отскакивает и оказывается рядом;
- между ними появляется короткая подсветка трубок;
- пара становится **Linked**.

### Усиленный запуск

Если в начале следующей своей активации две жабы всё ещё Linked:

- игрок выбирает одну из них;
- её собственная активная колба становится первым реагентом;
- активная колба второй жабы становится вторым;
- preview сразу показывает будущую реакцию;
- следующий прыжок создаёт **комбинированный эффект при приземлении**.

После запуска Link исчезает.

Переключается только колба той жабы, которая реально прыгнула.

Колба партнёра не меняется.

## 12.3. Зачем прыгать на союзника

Это намеренная потеря мгновенного давления ради сильного следующего действия.

Противник получает одну активацию, чтобы:

- разорвать пару knockback'ом;
- уйти из потенциальной зоны;
- изменить поверхность;
- подготовить ответ.

Поэтому Link является читаемой подготовкой комбо, а не бесплатным burst.

# 13. Шесть базовых жаб

Все жабы могут использовать любые четыре базовые жидкости.

Разница между ними — не новый набор кнопок, а **то, как они меняют общий toy**.

## 13.1. IRON RAM
### Тяжёлый таран

**Роль:** impact / destruction

**Особенности:**
- высокий HP;
- самая высокая Mass;
- короткий Jump;
- высокий Impact.

### Passive — Battering Landing
Если прыжок заканчивается прямым попаданием или приземлением рядом с разрушаемым объектом:
- +1 terrain damage.

### Сильные синергии
**+ Tongue Harpooner:** Harpooner подтягивает врага к треснувшему участку, Iron Ram завершает удар.

**+ Springjack:** Springjack помогает создавать Link-комбо, компенсируя короткую дальность Ram.

### Особенно хорош с
Force, Ember.

---

## 13.2. SPUR KNIGHT
### Жаба со шпорами

**Роль:** duelist / sustained damage

**Особенности:**
- средний HP;
- хороший Jump;
- средний Impact.

### Passive — Spurs
Прямое попадание по вражеской жабе накладывает **Bleed**.

Bleed:
- один дополнительный небольшой тик damage после следующей активации;
- не стакается, только обновляется.

### Сильные синергии
**+ Tongue Harpooner:** язык подготавливает удобную цель для прямого hit.

**+ Bellows Toad:** большие зоны заставляют противника двигаться предсказуемо, облегчая прямое попадание.

### Особенно хорош с
Frost, Force.

---

## 13.3. TONGUE HARPOONER
### Механический язык-лебёдка

**Роль:** control / setup

**Особенности:**
- средний HP;
- длинный Jump;
- низкий Impact.

### Passive — Harpoon Tongue
После приземления Harpooner автоматически выбирает ближайшую вражескую жабу в коротком радиусе.

Если между ними нет препятствия:
- механический язык цепляет цель;
- подтягивает её на небольшую фиксированную дистанцию к точке приземления.

Не отменяет ход противника и не оглушает.

### Сильные синергии
**+ Iron Ram:** ставит врага под тяжёлый удар.

**+ Bellows Toad:** затягивает врагов обратно в зоны.

### Особенно хорош с
Venom, Frost.

# 14. Примеры простых командных связок

## Iron Ram + Tongue Harpooner
**Pull → Smash**

1. Harpooner приземляется рядом.
2. Подтягивает врага.
3. Ram получает простой прямой hit.
4. Force/Meteor ломает арену под целью.

## Bellows Toad + Tongue Harpooner
**Zone → Pull Back**

1. Bellows создаёт большую Venom/Frost-зону.
2. Враг пытается уйти.
3. Harpooner возвращает его внутрь.

## Aegis Toad + Springjack
**Load → Launch**

1. Springjack прыгает на Aegis.
2. Пара становится Linked.
3. Следующий запуск получает две жидкости и увеличенную дальность.
4. Игрок отправляет реакцию почти через всю арену.

## Spur Knight + Frost Bellows
**Slow → Hit**

1. Bellows создаёт большую Frost-зону.
2. Враг получает Chill.
3. Его следующий прыжок короче.
4. Spur Knight легче предсказывает позицию и наносит прямой hit с Bleed.

# 15. Урон и физика

## 15.1. Основные источники damage

1. Direct Impact.
2. Жидкость.
3. Reaction.
4. Status:
   - Poison;
   - Bleed.
5. Environmental damage.
6. Столкновение после сильного knockback.

## 15.2. Knockback

Knockback зависит от:

- скорости атакующего;
- Mass атакующего;
- Mass цели;
- Force;
- конкретной реакции.

Игроку не показывается формула.

В preview показывается стрелка ожидаемого смещения.

## 15.3. Friendly Fire

Союзнику нельзя нанести прямой HP damage своим прыжком.

Но союзника можно:
- слегка сместить;
- использовать для Link;
- случайно вытолкнуть в неудобную позицию сильной реакцией.

AoE-реакции не наносят HP damage союзнику в MVP, но могут физически его сдвигать.

Это сохраняет тактику, не превращая игру в наказание за эксперименты.

# 16. Победа

В MVP одно условие победы:

> **вывести из строя обе вражеские жабы.**

Жаба при 0 HP:
- ломается;
- выпускает пар;
- опрокидывается;
- остаётся декоративным обломком до конца матча;
- больше не создаёт Link и не блокирует движение.

Последняя команда с хотя бы одной рабочей жабой побеждает.

# 17. Anti-stall / эскалация

Чтобы игроки не бесконечно избегали друг друга:

После **6-го раунда** начинается `ARENA OVERLOAD`.

Каждый новый раунд:
- часть внешнего кольца арены становится Cracked;
- алхимические трубки начинают нестабильно светиться;
- безопасное пространство постепенно уменьшается.

Это не отдельное условие победы.

Оно просто заставляет команды закончить Deathmatch.

# 18. Мета

## 18.1. Что коллекционирует игрок

Главная коллекционная сущность — **жабы**.

Не существует отдельной коллекции карт приказов.

Игрок:
- открывает жаб;
- получает их копии / ресурсы;
- повышает уровень;
- собирает пары;
- настраивает три колбы.

## 18.2. Что прокачивается

Уровень жабы увеличивает небольшими шагами:

- HP;
- Impact.

На milestone-уровнях немного улучшается signature passive.

Пример:

**Iron Ram Lv.4 → Lv.5**
- HP +4%;
- Impact +3%;
- Battering Landing: увеличивается радиус взаимодействия с объектами.

Геометрия прыжка и основные правила персонажа не меняются.

## 18.3. Что НЕ прокачивается отдельно

В MVP жидкости не имеют уровней.

Ember всегда означает Ember.

Venom всегда означает Venom.

Это важно для PvP-читаемости.

Сила эффекта может слегка масштабироваться общим уровнем жабы, но правило и визуальный результат остаются одинаковыми.

# 23. Короткий матч-пример

Команда Blue:

- Springjack: `Ember → Frost → Force`
- Aegis Toad: `Venom → Force → Ember`

Команда Red:

- Iron Ram: `Force → Ember → Venom`
- Tongue Harpooner: `Frost → Venom → Force`

### Раунд 1

Springjack прыгает на Aegis.

Они становятся Linked:

`Ember + Venom = BLAST`

Red видит подготовленное комбо.

Iron Ram вместо атаки ломает центральную колонну Force-приземлением и создаёт опасную линию.

Aegis запускается из Link и вызывает Blast около Harpooner.

Harpooner отвечает Frost-прыжком и языком подтягивает Aegis к треснувшему участку пола.

После одного раунда:

- урон уже нанесён;
- часть арены изменилась;
- обе команды сменили активные колбы;
- следующий набор возможных реакций уже другой.

Это и есть желаемый ритм:

> **простое управление, но постоянно меняющееся тактическое состояние.**

# 24. Главные риски

## Слишком много элементов
Решение:
- всего 4 жидкости;
- максимум 2 элемента в реакции;
- preview всегда показывает результат.

## Игрок считает колбы вместо того, чтобы играть
Решение:
- физические колбы всегда видимы;
- активная и следующая выделены;
- последовательность никогда не скрыта.

## Link слишком медленный
Решение:
- сильный reward;
- не требовать дополнительного меню;
- landing on ally автоматически создаёт Link.

## Разрушение превращает карту в хаос
Решение:
- ломается только заранее определённое окружение;
- большая часть основного пола остаётся надёжной;
- состояние `Intact → Cracked → Destroyed` всегда визуально очевидно.

## Power progression решает PvP
Решение:
- небольшие приросты;
- уровневые cap'ы для соревновательных режимов;
- основная сила билда идёт из пары и жидкостей, а не из разницы в цифрах.

# 25. Design Reference Notes

**Divinity: Original Sin 2 — Definitive Edition / Arena Mode**

Из официальных материалов как референс используются:
- PvP Arena с отдельными тактическими картами;
- Deathmatch;
- уникальные персонажи с индивидуальными способностями;
- Mutators, меняющие условия поздних раундов;
- общий принцип комбинирования огня, льда, воды, яда и других поверхностей/элементов.

TOADBREW не переносит конкретные навыки, персонажей или формулы DOS2. Из референса берётся только системный принцип:

> **создать состояние поля → следующим действием превратить его в более сильный и понятный результат.**
