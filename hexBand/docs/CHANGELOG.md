## [0.2.0] — 2026-09-22

### Изменено
- **Структура хода** (по указанию дизайнера, D-022): за ход можно сыграть любое число карт с руки, минимум одну. Эффект каждой карты применяется сразу при розыгрыше, карта тут же уходит в сброс. Ход завершается кнопкой «Завершить ход» (активна после первой сыгранной карты). Добор до 4 карт по-прежнему только в начале хода. Пропуск хода со сбросом карты доступен только если в этом ходу ещё ничего не сыграно.
- Бот играет карты по одной, пока очередная карта улучшает оценку позиции хотя бы на 0.3, затем завершает ход.
- Подсказка над рукой показывает число сыгранных карт; текст правил обновлён.
- `sim.html` учитывает новый цикл хода и показывает среднее число карт за ход.

### Добавлено
- **Пиктограммы на картах** (D-023): `js/icons.js`, монохромные inline-SVG для всех 23 карт — стрелки движения (число шевронов = число шагов, наклон = диагональ), круговая стрелка для поворота, фигурки миньонов с числом, меч для атаки, щит для защиты, глаз для Overwatch, флаг для Claim, пунктирная стрелка для Blink. Показываются в руке и в сборщике колоды.

### Исправлено
- На ширине экрана 430 px четвёртая карта руки вылезала за край: колонки сетки получили `minmax(0, 1fr)`, карты — `min-width: 0`.

### Замечено, не изменено
- Симуляция бот-бот, 48 партий, 10 раундов: бот играет в среднем 1.65 карты за ход (максимум 6), уничтожений 12 из 48 (было 0), атак 3.9 на партию (было 2.4), территория ~14.5 гексов у каждого (было ~12). Человек, играющий все 4 карты за ход, будет и красить, и бить заметно быстрее бота — см. D-022 о последствиях.

## [0.1.0] — 2026-09-22

Первый играбельный прототип по GDD (docs/GDD.md), объём — MVP из §32 плюс продвинутые карты и все POI.

### Добавлено
- Поле 7 колонок, 74 гекса, flat-top, зеркально симметричное (D-002); стартовые зоны по 6 гексов; 6 слотов POI, по 3 на сторону.
- Покраска пройденных гексов, заливка замкнутых контуров (D-004), подсчёт Territory Points с бонусом Claim.
- Точки интереса: захват проходом или контуром, карта POI наверх колоды с немедленным добором, удаление карты при потере POI из руки/колоды/сброса (§6).
- Отряд с числом миньонов, facing по 6 направлениям, зоны Front / Side / Back (D-003).
- Бой после любой карты при противнике во фронтальной дуге, модификаторы 1.0 / 1.25 / 1.5, тексты FLANK! / BACKSTAB! (D-006, D-007).
- Колода 8 карт, рука 4, цикл колода → рука → сброс с перемешиванием.
- 15 карт: 8 базовых (§12) и 7 продвинутых (§13); 8 POI и их карты (§16); 4 пресета колод (§14–15).
- Экран сборки: выбор 8 карт из 15 и 3 POI из 8 для каждого игрока, пресеты, лимит раундов, seed, переключатель поворота на диагональном шаге (D-005).
- Режимы: против бота (жадный перебор на 1 ход, D-014) и hotseat с оверлеем передачи устройства.
- Условия победы: уничтожение, территория по лимиту раундов, тай-брейки POI → миньоны → захват в последнем раунде (§22).
- Canvas-отрисовка: территория, POI, кластер миньонов с баннером, дуга фронта, превью пути, подсветка целей, анимации движения, вспышки покраски, волна заливки, всплывающие тексты, тряска при ударе (§27).
- HUD: раунд, доля территории, миньоны и POI обеих сторон; журнал матча; подсказки по гексу кликом; окно правил.
- `sim.html` — массовая симуляция бот-бот для замера баланса.
- `tools/serve.ps1` — статический сервер на PowerShell для локальной отладки (Node/Python на машине нет).
- Документация: `docs/GDD.md` (исходный документ), `docs/DECISIONS.md`, этот файл, `docs/index.html` — просмотрщик.

### Исправлено в ходе тестирования (до публикации)
- `config.js`: ключ объекта `1Light` без кавычек — синтаксическая ошибка, из-за которой не загружался ни один скрипт.
- CSS: `display: flex` у секции игры перебивал атрибут `hidden`, экран матча просвечивал под экраном настройки. Добавлено правило `[hidden] { display: none !important }`.
- Канвас измерялся до отрисовки руки и перекрывал её; размер теперь пересчитывается через `ResizeObserver`, обёртка получила `overflow: hidden`.
- Анимация движения падала с `Cannot read properties of undefined (reading 'y')`, если timestamp `requestAnimationFrame` оказывался меньше `performance.now()` момента старта: прогресс уходил в минус, индекс сегмента становился −1. Прогресс зажат в [0, 1]; цикл кадров обёрнут в try/catch, чтобы одна ошибка больше не останавливала отрисовку навсегда.

### Замечено, не изменено
- При 10 раундах и одной карте за ход карта используется примерно на 30 %, контуры замыкаются редко — см. D-020. Числа не трогались: это вопрос дизайнера после живых плейтестов.
